# v0.5.0-beta GitHub 공개 기준

작성: 2026-09-13. 최신 사용자 지시에 따라 **서버는 점검 중이므로 동기화·SSH·재배포를 하지 않는다.** 앱, README, 사이트 소스는 GitHub에 반영하고 클라이언트와 선택형 Lite 모델을 GitHub 베타 릴리스로 공개한다.

## 검증한 범위

- 앱 변경은 [677 검사 후보 기록](translation-candidate-677-v050.md)의 코드로 동결했다. 공개 직전 자동 검사 677/677을 다시 통과했다.
- Lite 호스트 단위 검사 5/5, Fast OCR 환경에서 OCR 단위 검사 12/12 통과. 처음 Lite 환경으로 OCR 검사를 실행했을 때는 Pillow 미설치로 수집 실패했으며, 실제 OCR 환경에서 재실행하여 확인했다. GPU OCR 종단 검사를 새로 수행한 것은 아니다.
- 두 모델의 120상황 × 4방향 × 2모델 실제 번역 960건은 위 기록을 따른다. 모든 출력이 정확했다는 뜻이 아니며, 1.8B와 7B 모두 의미 오류가 남는다.
- 커밋 전 검증 DLL과 커밋 후 배포 DLL은 커밋 정보가 달라질 수 있다. 배포 파일은 깨끗한 소스 커밋에서 다시 빌드하고 manifest, ZIP SHA256, GitHub 재다운로드 SHA256을 확인한다.
- UI 자동화는 사용자의 중단 의사를 유지하여 재개하지 않는다. 이전 E2E 결과를 새 배포 파일의 화면 검증으로 주장하지 않는다.

## 추가 발견했지만 이번 공개본에서 미해결인 사례

`testdata/translation-quality/trap-ownership-v050.tsv`는 다음 수정용 회귀 표본이다. 현재 통과를 보장하는 표본이 아니다. 로컬 원시 결과는 `artifacts/quality-v050/trap-baseline`에 있다(8상황 × 4방향 × 2모델 = 64건).

- ‘사이퍼 트랩’의 소유자를 호격으로 바꾸거나 tripwire를 잘못 번역하는 사례.
- 트랩 설치를 스파이크 설치로 옮기는 사례. 일반 설치 용어와 물체별 문맥을 분리해야 한다.
- 정상 일본어 금지 표현 `触るな`를 부정 누락으로 잘못 보류하는 사례.
- `short break`를 맵 위치 Short로 해석하는 사례. 프롬프트의 용어 선택과 위치 검사 양쪽을 함께 고쳐야 하며, 검사만 해제해서는 안 된다.

새 프롬프트 실험을 검증 없이 공개본에 섞지 않는다. 위 사례와 기존 조건·화자 오류는 다음 품질 개선에서 반례까지 비교한다. Lite 자유 문장으로 강제 대체하지 않는 정책은 유지한다.

## 공개 절차

1. 릴리스 관련 소스와 문서를 검토·커밋하고 GitHub에 정상 push한다. 기존 릴리스는 변경하지 않는다.
2. `Package-Release.ps1`로 clean sourceCommit이 담긴 ZIP과 SHA 파일을 생성한다.
3. `Release-GitHub.ps1`의 CheckOnly 확인 후 Publish를 실행한다. 초안의 네 파일을 다운로드하여 SHA256이 맞을 때만 prerelease로 공개한다.
4. 공개 릴리스 상태와 공개 다운로드를 확인한다. 서버 배포는 실행하지 않는다.

이 문서는 공개 직전 기준이다. 공개 성공 여부는 실제 GitHub 릴리스 상태를 확인해야 한다.
