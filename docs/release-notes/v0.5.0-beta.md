# Valtrans v0.5.0-beta

게임 채팅의 뜻을 지키는 번역과 다국어 OCR 안정성을 보완한 베타 업데이트입니다.

## 주요 변경

- **품질 우선 스마트 복합**: 검증된 짧은 콜은 사전으로, 그 외 문장은 선택한 로컬 AI로 번역합니다. AI 실패 시 신뢰하기 어려운 Lite 자유 문장으로 자동 대체하지 않습니다. 기본 모드에는 Lite 설치가 필요하지 않습니다.
- **수신 콜 누락 보완**: 발소리·엄호·힐·무기 구매 등의 콜이 브리핑 필터에서 빠지는 경우를 줄였습니다. 채택한 메시지는 조건과 정정 내용을 포함해 전체 문장으로 전달합니다.
- **정상 번역 차단 보완**: 한국어 ‘모른다·모릅니다’와 일본어 정중한 부정 표현을 더 잘 인식합니다. 방향·숫자·부정이 실제로 바뀐 결과는 계속 보류합니다.
- **브리핑 보존**: 방향·인원·부정·조건·불확실성·피해 수치·무기 용어를 보완했습니다. 수신 브리핑에서 중요한 조건절을 버리고 일부 문장만 남기는 문제를 수정했습니다.
- **일본어 검사 개선**: ‘너’를 뜻하는 お前의 前를 ‘앞쪽’으로 잘못 판정해 정상 번역을 막던 문제를 수정했습니다.
- **문맥 보완**: 무기 소유자를 임의로 ‘나’로 만들던 일부 경고 표현, 개인 계획을 초대로 바꾸던 표현, 빈정거림을 농담으로 옮기던 사례를 개선했습니다.
- **OCR 개선**: Fast OCR의 한·영·일 인식 선택과 여러 줄 채팅 연결을 보완했습니다. Hybrid에서 점수가 제공되지 않은 VL 결과를 잘못 버리던 문제를 수정했습니다.
- **반복 인식 비용 절감**: 정확히 같은 픽셀의 글줄만 메모리 캐시로 재사용합니다. 실제로 바뀐 글자는 새로 인식합니다. 정상 실행에서 원본 화면을 캐시 파일로 저장하지 않습니다.
- **송신 보호**: 번역 도중 다른 창으로 이동하거나 새로 입력하면 기존 결과로 채팅을 덮어쓰지 않도록 확인합니다.
- **설치 안내 정리**: 선택한 번역 모델과 OCR 엔진에 맞게 시작 가이드를 안내하며, 기본 모드의 불필요한 Lite 설치·예열·호환성 요구를 제거했습니다.

## Lite 별도 모드

KO→EN 모델의 원본 어휘/토크나이저와 INT8 변환을 재검토하고, 모델 패키지 무결성·활성화 및 재사용을 보완했습니다. 추가 학습을 한 모델은 아닙니다. Lite의 자유 문장과 일본어 중간 번역에는 여전히 큰 오역이 있어 정확한 팀 소통에는 로컬 AI를 먼저 사용해 주세요.

## 알려진 한계

- 1.8B와 7B 모두 화자, 조건, 인용, 체력 은어를 잘못 번역할 수 있습니다. 검사 통과가 정확도를 보장하지 않습니다. 보내기 전 결과를 확인하고 Enter로 전송하세요.
- 트랩 소유자·설치 대상이나 일반 표현의 `short`를 맵 위치로 잘못 옮기는 사례가 남습니다. 일부 일본어 금지 표현은 정상 번역도 보류될 수 있습니다.
- 7B는 일부 표본에서 더 나았지만 메모리 사용량과 지연이 늘어납니다. 게임 실행 상태에서 비교해 선택하세요.
- Fast OCR 단독은 C를 ㄷ으로 읽는 등의 오독이 남아 있습니다. Hybrid의 추가 인식이 도움 될 수 있지만 매번 해결되지는 않습니다.
- 새 채팅 인식과 번역에 수 초가 걸릴 수 있습니다. 첫 모델 준비·다운로드 시간은 일반 번역 시간과 별개입니다.
- 최초 설치에는 인터넷 연결이 필요합니다. 채팅의 OCR·번역 처리는 로컬에서 이루어집니다.

## English summary

This beta improves meaning-preserving translation, multilingual OCR, wrapped chat reconstruction and setup guidance. Smart Hybrid now uses verified callout rules plus the selected local AI; it does not fall back to unrestricted Lite translations when the AI fails. Lite remains an optional separate engine.

Translation errors and multi-second OCR delays remain possible. Larger models can improve some examples but use more memory and time. Review outgoing translations before sending. Initial installation needs internet access; chat recognition and translation run locally.
