MADE FOR THE MOMENT

게임 채팅을 더 편하게

짧은 브리핑부터 팀원과의 대화까지, 게임 화면에서 번역을 확인하세요.

01

VALORANT 맞춤 OCR

채팅 영역을 자동 계산하고 16:9가 아닌 해상도도 보정합니다. Fast·Hybrid로 일본어·중국어·혼합 콜을 읽고, 생략된 메시지는 오버레이에 이유를 표시합니다.

02

콜아웃의 뜻을 먼저

약어·게임 용어를 참고하고 방향·인원·부정 표현을 확인합니다. 검사에서 정보가 달라진 번역은 표시하지 않습니다. 오역이 모두 걸러지는 것은 아닙니다.

03

로컬 전용

짧은 콜은 사전으로, 그 외 문장은 Hy-MT2로 번역합니다. 기본 모드에는 Lite나 외부 번역 API가 필요하지 않습니다.

GET STARTED

첫 게임 전, 세 가지만

앱을 준비하고, 채팅을 읽을 언어를 골라보세요.

01

한 번에 설치 준비

시작 가이드에서 ‘권장 구성 설치·적용’을 누르세요. Hy-MT2와 Paddle OCR을 차례로 준비합니다. 기존 설정을 유지하려면 개별 설치 버튼을 이용하세요.

02

읽을 언어 선택

대시보드에서 채팅을 읽을 언어를 골라주세요. OCR 준비 상태와 자동으로 잡힌 채팅 영역도 바로 확인할 수 있습니다.

03

게임에서 번역 시작

받는 채팅은 오버레이로 읽고, 보내는 채팅은 단축키로 번역하세요. 번역 중 새로 입력하거나 다른 창으로 옮기면 교체를 취소합니다. 결과 확인 후 Enter로 전송하세요.

Valtrans는 VALORANT 전용입니다. 일본어 채팅은 Fast 또는 Hybrid OCR을 권장합니다(Windows OCR 일본어 한계). Paddle VL은 NVIDIA GPU가 필요합니다. 자세한 사용법은 README 가이드에서 확인할 수 있습니다.
