# 번역 품질과 측정 한계

현재 기능 기준의 참고 문서입니다. 측정일은 2026-09-07이며 아래 수치는 해당 PC의 제한된 예문 실험입니다. 게임 실행 중 FPS나 전체 채팅 지연 측정은 아닙니다.

## 로컬 AI

기본 구성은 Hy-MT2 1.8B 우선 + Lite 대체입니다. 7B는 선택할 수 있으며 모델별 입력 템플릿·종료 토큰을 따로 사용합니다. 설치된 모델 선택을 버전 정리 때문에 바꾸지 않습니다.

| 비교 | Hy-MT2 1.8B | Hy-MT2 7B |
| --- | ---: | ---: |
| 로드 포함 최초 요청 | 5,353ms | 8,483ms |
| 이후 11문장 중앙값 | 241ms | 633ms |
| Ollama 보고 GPU 적재량 | 1.35GiB | 4.91GiB |

12개 예문 단일 실행 비교입니다. GPU 적재량은 시스템 전체 최고 사용량이 아닙니다. 7B에서 인사·조건·일부 은어가 개선됐지만 `아직 들어가진 마`를 아직 들어가지 않았다는 진술로 바꾸는 오류가 남았습니다. 빈 결과가 없다는 사실도 정확도 100%를 뜻하지 않습니다.

## Lite

Argos EN↔KO·EN↔JA 패키지를 사용하며 JA↔KO는 영어를 거칩니다. 동일 설치 모델에 6방향×4문장, 후보 수 1/2/4를 비교했습니다. 테스트 환경은 CTranslate2 4.8.2 / SentencePiece 0.2.1, CPU INT8, 4스레드이며 각 항목 예열 후 2회 측정했습니다.

| 후보 수 | 문장별 예열 추론 중앙값의 중앙값 |
| --- | ---: |
| 1 | 19.7ms |
| 2 | 26.5ms |
| 4 | 27.6ms |

배포 호스트와 테스트 런타임 차이가 있을 수 있습니다. 모델 로드·프로세스 시작·OCR 비용은 제외했습니다.

- `左には行かないで、右に行って`: 후보 2는 금지를 유지했지만 후보 1/4는 `Turn left and turn right`로 금지를 누락했습니다.
- `たぶん右に二人、左にはいない` → KO: 모든 후보 수에서 추정·부정이 빠졌습니다.
- 일부 인사는 후보 4에서 더 자연스러웠지만 게임 표현의 오역도 남았습니다.

따라서 빠른 후보 수 1을 유지합니다. 더 많은 후보가 항상 더 정확하지 않으며 큰 모델을 Lite에 추가하지 않았습니다.

Lite 단독과 Hybrid 대체 결과는 보정 전에 같은 검사로 검증합니다. 빈 결과·깨진 토큰·비정상 반복·미번역·포착 가능한 방향/수치/부정/불확실성 누락은 보류합니다. 부정어를 앞에 붙여 추측 번역을 만들지 않습니다. 검사 통과는 정확도 판정이 아니며 정상 동의어를 보류하거나 유창한 오역을 놓칠 수 있습니다.

## OCR 및 검증

Windows OCR의 언어별 후보를 줄 위치로 대응시켜 고르고 단어 좌표를 보존합니다. 합성 후보를 이용한 줄 선택 테스트는 실제 이미지 인식 정확도 측정이 아닙니다. 글꼴·배경·해상도에 따라 직접 영역 보정과 인식 확인이 필요합니다.

규칙 회귀, API 모의 응답, Lite 검사, 취소 응답 처리 테스트를 함께 유지합니다. 실제 모델 비교 스크립트도 남겨 두어 측정을 재현할 수 있습니다. 과거 버전별 원시 보고서는 프로젝트 정리 대상으로 분리했습니다.
