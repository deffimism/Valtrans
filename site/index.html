MADE FOR THE MOMENT

플레이를 끊지 않는 번역

긴 설명 대신, 브리핑에 필요한 표현을 짧고 분명하게 보여줍니다.

01

다국어 OCR

PaddleOCR-VL로 혼합 언어 채팅을 읽습니다. 게임 창에 맞춰 영역을 자동 계산하고 중복·시스템 문구를 걸러냅니다.

02

FPS 표현 최적화

nt, mb, mid 같은 약어와 방향·콜아웃을 게임 문맥에 맞춰 처리합니다.

03

로컬 전용

Hy-MT2 1.8B와 Lite가 PC에서 번역합니다. 외부 번역 API·키·Docker·WSL은 필요하지 않습니다.

GET STARTED

첫 게임 전, 세 가지만

앱을 준비하고, 채팅을 읽을 언어를 골라보세요.

01

한 번에 설치 준비

시작 가이드에서 ‘권장 엔진 준비’를 누르세요. 설치를 승인하면 번역 엔진과 Paddle OCR을 차례로 준비합니다.

02

읽을 언어 선택

대시보드에서 채팅을 읽을 언어를 골라주세요. OCR 준비 상태와 자동으로 잡힌 채팅 영역도 바로 확인할 수 있습니다.

03

게임에서 번역 시작

받는 채팅은 오버레이로 읽고, 보내는 채팅은 단축키로 번역하세요. 결과를 확인한 뒤 Enter로 전송하면 됩니다.

기본 OCR은 NVIDIA GPU가 필요합니다. 가볍게 사용하려면 Windows OCR을 선택하세요. 설치 조건과 자세한 사용법은 가이드에서 확인할 수 있습니다.
