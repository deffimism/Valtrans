## 변경 사항

- Fast 인식기: 언어 모델·이미지 크기·RGB 픽셀 SHA256이 모두 같은 조각만 메모리에서 재사용한다. 좌표 이동만으로 재인식하지 않지만 한 픽셀 차이도 새 입력으로 처리한다.
- 최대128개 LRU. 저장하는 것은 해시/크기/인식 결과이며 원본 이미지나 디스크 캐시는 저장하지 않는다. OCR worker 종료 시 함께 사라진다. 캐시를 끄고 비교하는 검사 옵션도 있다.
- 같은 배치 내 중복 이미지도 결과 순서/개수를 유지하면서 한 번만 인식한다. 인식기/크기 분리, 픽셀 변경, 한도/비활성화, 순서 보존 테스트 추가.
- Hybrid 단계별 `fastMs`, `retryMs`, `vlMs`, `totalMs`, `selected`를 내용 없는 성능 로그로 남긴다. VL을 호출했지만 Fast 결과를 유지했다면 `fast-after-vl`로 구분한다.
- Hybrid 캡처 시간에 최신 영역 추가 캡처를 포함하고 전체 시간은 캡처+모든 인식 시도로 계산한다. 이미 캡처된 입력을 넘기는 경로에서 전체 시간의 캡처 누락을 수정했다.
