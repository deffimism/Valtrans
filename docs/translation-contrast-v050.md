# v0.5.0-beta 번역 의미 대조 검사 — 2026-09-13

릴리스 완료 보고서가 아니다. 앱/사이트 버전·배포는 아직 v0.5로 전환하지 않았다.
이 기록의 A/W/E/X는 에이전트가 원문과 실제 출력을 대조한 판정이며 내부 validator PASS와 다르다.
A=사용 가능, W=어색/모호, E=의미 오류, X=차단/실행 실패. X를 정답으로 세지 않는다.

## 프롬프트·용어 실험

- 위치 참고 항목을 `Map location`으로 명시하고, 문맥이 확인되는 단일 A/B/C 사이트만 참고한다. 키보드/성적/플레이어 이름의 B는 위치로 강제하지 않는다.
- 경기·라운드 대비, 잠깐 기다리라는 `One second`, 회선이 끊겨 게임에서 나간 `抜けた`를 관련 문맥에서만 참고한다. 치아가 빠졌다는 `歯が抜けた`는 게임 이탈이 아니다.
- 이전 믿음과 실제 사실, 대신 사주는 제안의 행위자, 피해를 준 쪽과 받은 쪽, 조건문을 보존하는 관련 지시를 추가했다. 긴 지시가 모든 문장의 의미 오류를 해결하지는 않았다.
- `fidelity-hints`: 기존 32상황×4방향을 1.8B/7B로 실제 256건 실행. 출력/오류가 동일한 경우만 이전 판정을 이어받고 변경 출력은 직접 재검토했다.

| 모델 | 이전 A/W/E/X | 이번 A/W/E/X |
|---|---|---|
| 1.8B | 82/21/19/6 | 92/17/15/4 |
| 7B | 95/21/10/2 | 106/17/3/2 |

이미 수정에 사용한 회귀 표본이다. 일반 정확도나 미관측 문장 정답률로 홍보하지 않는다. 이전 표본 이후의 완전 문법 수정(205/212)도 포함되어 있어 전부 이번 프롬프트만의 효과라고 할 수 없다. 제안/부정/시제 오류와 일부 새로운 차단도 남았다.

## 새 의미 대조군

`testdata/translation-quality/semantic-contrast-v050.tsv`: 8상황×4방향. 착각한 적/아군, 대신 무기 구매, 준 피해/받은 피해, 경기/라운드, 마이크 조건문, 초인종/복귀, 치아가 빠짐, 키보드 B/사이트 B.
최초 실행 후에는 회귀 표본이며 계속 미관측 표본이라고 부르지 않는다.

`fidelity-contrast` 최초 64건에서 정상 출력을 막는 검사 오류를 발견했다. 원시 재요청도 별도로 저장했고 같은 모델을 사용했는지 명시했다.

- `밴달 대신 팬텀`이 `instead of`의 부정을 잃었다고 차단됨.
- `라운드 하나 / ラウンド1つ`가 단위로 읽히지 않고 인원 또는 단위 변경으로 잘못 판정됨.
- 소문자 `site B`, 한국어 `메인 A`가 같은 위치의 다른 어순으로 처리되지 않음.
- `하나는 아군`의 하나를 인원으로 추출하지 못함.

단위·어순·조사 처리를 수정했다. 새 처리에서 `세이브`의 `세`가 숫자3으로 읽히는 회귀가 단위 테스트에 걸려 숫자 끝 경계를 보강했다. 중간 실행 `contrast-guard-fix`에서 인원 오탐을 제거하자, 잡담의 **실제 부정 누락**이 통과하는 별도 문제가 드러났다. 명시적인 ‘그런 뜻이 아니다’는 잡담에서도 부정을 확인하도록 추가했다. ‘no worries → 괜찮아’ 같은 관용적 긍정 표현을 무조건 막는 방식은 아니다.

## 최종 대조군 실제 실행

`artifacts/quality-v050/contrast-final`: 최종 빌드로 64건을 다시 실행하고 출력이 바뀐 항목을 재검토했다. 원본 JSONL·메타 SHA·판정 TSV·전체 표·집계를 보존한다.

| 모델 | 최초 A/W/E/X | 수정 후 A/W/E/X | 수정 후 P50/P95 |
|---|---|---|---|
| 1.8B | 9/6/7/10 | 11/7/7/7 | 250/369ms |
| 7B | 20/6/0/6 | 26/6/0/0 | 860/1151ms |

7B의 차단6건은 모두 동등한 사실을 가진 출력임을 확인했다. 1.8B의 사이트 누락·부정 누락·단위 변경 출력은 계속 차단한다. 특히 ‘한 경기 더, 라운드 하나라는 뜻은 아니야’의 일본어가 긍정으로 뒤집히는 출력은 `NEGATION_MISSING`으로 남는다. 차단 해제가 번역문의 모든 뉘앙스를 보증하지는 않는다.

1.8B의 가정/실제 경험 혼동, 피해 행위자 반전, 자기/우리 구별, 시제·복귀 오류는 남아 있다. 7B도 돈에 임의의 원화 단위를 추가하거나 행위자·조건·의도 표현이 모호한 W6건이 남았다. 이 32문장만으로 7B 전체 무오류를 주장하지 않는다.

## 검증 및 후속

- .NET **500/500 통과**. 단위·인원·사이트 변경을 여전히 차단하는 반대 사례, 영어 부정관사 a, 세이브, 잡담 부정 및 긍정 관용구 포함.
- `Inspect-TranslationRejections.ps1`은 입력 결과의 실제 모델 프로필을 사용하며 선택한 비교 모델만 순차 해제한다. 이전 1.8B 고정 진단 문제 수정.
- `Summarize-TranslationQuality.ps1`은 briefing/social뿐 아니라 원본 데이터에 있는 모든 category를 집계한다.
- 전체 원래 corpus 320×2 재검사와 변경 출력 전수 판정도 완료했다. 아래 후속 결과를 우선한다.
- 앱/README/사이트 v0.5 변경, 공개 Lite 모델 asset, 릴리스 패키지·SHA 및 운영 배포는 후속 단계다. 서버 전용 무인자 배포 권한은 확인 완료했고 서비스는 재시작하지 않았다.

## 전체 320건/모델 회귀와 선택적 지시 공백

`release-regression`에서 640건을 끝내고 phase4 대비 바뀐 1.8B66건/7B30건을 직접 재검토했다. 동일 출력/오류만 이전 판정을 유지했다. A/W/E/X는 각각1.8B271/32/12/5, 7B304/10/5/1이었다. 추가 대조군의 개선이 전체 표본 개선을 보장하지 않는다는 증거다.

프롬프트에 해당하는 추가 지시가 없는 경우에도 빈 줄을 하나 더 넣던 부분을 제거했다. 이 수정은 관계없는 입력의 프롬프트 토큰을 바꾸지 않기 위한 것이며, 모든 생성 변화를 공백 하나의 효과로 일반화하지 않는다. `prompt-layout-regression`에서 다시640건 실행, 직전 대비 1.8B44건/7B8건 변경을 직접 검토했다.

| 모델 | 최신 A/W/E/X | P50/P95 |
|---|---|---|
| 1.8B | 272/36/8/4 | 141/249ms |
| 7B | 304/10/5/1 | 347/811ms |

DLL SHA256: `34E59CD62150F9E194B09FC3A52E539552C7480FC5F8EFED8C75BF140A6FCE9F`.
500개 단위 테스트 및 whitespace 검사 통과. 이번 턴의 모든 모델 검사 프로세스는 종료되었고 benchmark가 적재한 대상 모델도 정리됐다.

`Merge-TranslationReview.ps1`은 변경 출력마다 명시적인 판정을 요구하고, 원문/목표 언어 변경·누락·중복·오류/X 불일치를 거부한다. 각 결과 폴더에 수동 변경 판정TSV, 생성한 전체 판정TSV/CSV/Markdown/summary를 보존했다. `release-regression`은 공개 릴리스 완료라는 뜻이 아니라 회귀 실행 폴더 이름이다.

### 아직 처리해야 하는 주요 사례

- 1.8B/7B 모두 `걔 원탭이야`를 남은 체력보다 공격 능력으로 옮기는 경우.
- 7B `後ろについてトレードして`의 지시가 과거 보고로 변함.
- 복합 콜 `B 메인 둘, 한 명은 오퍼고 다른 한 명은 딸피` 및 영어/일본어 수신: 무기/체력 역할이 섞이거나 인원·위치 검사로 차단됨. 원시 출력 재확인 후 실제 누락과 검사 오탐을 분리해야 한다.
- 1.8B 감사/모욕/타인에게 한 말의 의도·행위자 오류, 7B 개인 계획→같이 하자는 제안 및 sarcasm→농담.
- 기존 추가128건과 새32건은 마지막 공백 변경 이후 전체 재검사 전이며 해당 표의 빌드를 최신 DLL과 혼동하지 않는다.
- 다음 턴은 위 남은 번역 의미 오류 및 원시 차단 확인에서 이어가고, 전체 품질 완료로 표시하지 않는다. 릴리스 버전/README/사이트/공개 모델 asset/패키지/서버 배포는 여전히 남아 있다.
