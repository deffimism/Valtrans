송신 KO→EN/JP, 수신 EN/JP→KO. 각 상황 네 방향을 두 모델로 실행했다. 숫자를 독립적인 960개 상황이나 미공개 검증 데이터로 표현하지 않는다. OCR 없는 번역 경로 검사이며 수신 필터는 All이다. 격리 모델로 실행했고 예열은 아래 지연에서 제외했다.
