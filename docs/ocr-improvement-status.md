# OCR 종합 개선 진행 기록

작성: 2026-09-08 / 앱 버전 **v0.1.1-beta 유지**

## 반영 내용

- Windows OCR: 시스템 문구는 번역 대상이 아니어도 **올바른 인식 후보**로 우선합니다. 한국어 UI를 가짜 일본어 후보로 바꾸던 문제를 교정했습니다.
- 읽기/번역 언어 분리: 한국어 UI 보조 인식을 사용하며, 선택한 원문 언어의 본문만 번역합니다. Windows 준비 시 한국어 OCR 팩도 확인합니다.
- 시스템 문구의 이어지는 줄, 방송, 입력 중인 `팀:` 줄, 날짜 라벨 제외. 실제 `(팀) 닉네임: 오늘` 메시지는 보존합니다.
- OCR 전용 손상된 채널 헤더 제거 강화. 숫자·방향·부정·불확실성 변경은 유사 중복 판단에서 보호합니다.
- 화면 변화 해시는 밝은 픽셀의 개수뿐 아니라 위치도 유지합니다. 원본 글자가 달라도 개수만 같아 변화가 누락되는 위험을 줄입니다.
- 학습한 확대 보정이 빈 결과/명백한 잡음을 만들면 원본을 다시 비교합니다. 원본보다 나쁜 빈 보정을 강제로 선택하지 않습니다.
- 번역 완료 즉시 한 줄씩 표시, 실패한 줄만 제외. 대기 최대 8줄, 대기 20초 만료, 처리 15초 취소. OCR 중지/재시작의 작업 소유권 분리.
- PaddleOCR-VL 선택형 로컬 경로: 설치, 폴더 선택, 모델 준비 상태, 취소/메모리 해제, 실제 OCR 테스트에 연결했습니다.
- Paddle은 전체 채팅 영역을 한 번 읽고, Windows 전처리/이중 영역/두 프레임 합의를 중첩하지 않습니다. 기본 OCR은 바꾸지 않았습니다.
- Paddle의 잘린 생성은 번역하지 않습니다. 3회 연속 오류면 자동 중지와 안내. 앱이 시작한 OCR 프로세스만 종료합니다.
- 테스트 창에서 원문과 헤더/시스템 제거 후 본문을 함께 확인할 수 있습니다.
- VALORANT 추천 영역을 제공된 전체 화면의 비율(X 1.25~24%, Y 72.5~95.2%)로 교체했습니다. 펼친 채팅 전체를 포함하고 입력줄은 제외합니다. 게임 창 내부 좌표를 우선합니다. 5개 해상도와 음수 모니터/창 위치를 회귀 검사합니다.

## 후속 요청: 로컬 전용·단순화

- 수동 영역 선택·보정 마법사·최신 영역 선택 제거. 게임 창의 위치와 크기로 자동 추천하며 예전 수동 영역보다 새 추천값을 사용합니다. 표시 기능은 전체 영역 한 곳만 보여줍니다.
- OCR 시작 버튼을 카드 상단으로 옮기고 OCR 엔진·필터·안정화·진단은 대시보드의 접힌 설정에 모았습니다. 오버레이 페이지에는 위치·크기·투명도·글자 크기·표시 시간만 남겼습니다.
- 외부 LLM/DeepL API·DLX/Docker 준비 UI, 요청 경로, 자격증명 저장 코드를 제거했습니다. 이전 외부 엔진 설정은 로컬 기본값으로 전환하고 키 필드는 다음 저장부터 제외합니다. 사용자가 설치한 Docker/WSL 자체는 제거하지 않습니다.
- 맵 선택과 맵별 위치 사전·프롬프트 분기 제거. 기존 캐릭터 고유명사와 공통 콜아웃은 유지하고, Riot 맵 안내에서 확인한 맵 고유명사를 사전에 추가했습니다. 맵을 추측해 램프를 Ramp/Lamps로 바꾸는 분기는 없습니다.
- 검증: 28가지 이전 설정 전환, 로컬 모델·언어·단축키·사전 유지, 퇴역 API/수동 캡처 타입이 배포 DLL에 없는지 확인, 받기/보내기 8회 모의 요청이 루프백 주소만 사용하는지 확인.
- 공식 명칭 참고: https://playvalorant.com/ko-kr/maps/ · https://playvalorant.com/ja-jp/maps/ · https://playvalorant.com/en-us/maps/

## 이진화 실험

`scripts/Test-OcrPreprocessing.ps1`로 동일한 사용자 이미지 3개에 원본/기존 확대 보정/지역 적응 이진화를 비교했습니다.
이진화는 RGB 최대 밝기와 주변 평균을 이용해 어두운 게임 배경에서 밝은 문자를 검출하고 검은 글자/흰 배경 후보를 만듭니다.

- 짧은 혼합 채팅 사례: 원본보다 일본어가 좋아짐. 하지만 기존 확대 보정도 같은 개선을 제공했습니다.
- 방송·시스템 사례: 일본어 `ミッド`의 앞부분이 누락되거나 문자가 깨짐.
- 따라서 **자동/기본 경로에 이진화를 적용하지 않았습니다.** 구현은 이미지 비교 진단용 `Binary` 모드로 남겼습니다.
- 결과: `artifacts/ocr-vl/preprocessing.json`. 이 실험의 지역 적응 방식 하나로 모든 이진화 기법의 효과를 부정하지 않습니다.

## 검증 및 남은 한계

- 사용자 스크린샷 비교: `docs/ocr-vl-evaluation-2026-09-08.md`와 `artifacts/ocr-vl` 참조.
- 합성 회귀: 시스템 후보/줄바꿈/닉네임/입력줄/숫자/부정 보호, 단일 실패 격리, 8줄 대기 상한, 중지 취소.
- 실제 GPU IPC: 혼합 채팅에서 `ミッド2 / mid 2 / 미드 둘` 추출, 중간 취소와 다음 준비 성공.
- Windows 기본 OCR은 개선됐어도 일본어 행 인식 오류가 남습니다. 모델이 읽지 못한 숫자/방향을 임의 생성하지 않습니다.
- `二/ニ` 혼동은 문맥 검증 없이 일괄 치환하지 않습니다.
- 실제 게임 프레임, 다른 GPU/해상도, 긴 세션의 중복·지연은 아직 실게임 검증이 필요합니다. 정적 스크린샷 결과를 게임 성능 보장으로 주장하지 않습니다.
- 다른 대형 OCR/VLM은 무제한 추가 다운로드하지 않았습니다. 현 단계에서는 확인된 Paddle 경로와 Windows 개선을 우선합니다.

실게임 확인 항목: 새 EN/JP 메시지 표시 → Enter로 기록 다시 열기 → OCR 중지/재시작 → 맵/해상도 전환 → 게임 중 GPU 부하와 지연.
