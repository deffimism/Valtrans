# PaddleOCR-VL 실측 결과 — 2026-09-08

앱 버전: **v0.1.1-beta 유지**. 아래는 통합 전 비교 실험의 기록입니다. 후속 작업에서 Windows 기본 OCR은 유지하면서 선택형 Paddle 경로를 앱에 통합했습니다. 현재 반영 사항은 [OCR 개선 기록](ocr-improvement-status.md)을 참조하세요.

## 결론

한·영·일 혼합 채팅 인식은 현재 Windows OCR의 언어별 결과 선택보다 이 세 사례에서 크게 개선됐다.
다만 채팅 전체를 매번 생성하는 방식은 예열 후에도 1.6~4.6초가 필요해,
기본 실시간 OCR을 즉시 교체하기보다 선택형 고정확도 모드의 후보로 두는 것이 적절하다.
게임 중 FPS, 장시간 사용, 다른 해상도/맵/폰트, 한 줄만 읽을 때의 지연은 미측정이다.

## 조건

- GPU: NVIDIA GeForce RTX 4070 SUPER 12GB. 다른 앱을 강제 종료하지 않은 현재 PC 상태.
- 공식 모델: `PaddlePaddle/PaddleOCR-VL-1.5`, 커밋 `2a4195faa5e7914c12f2fc601d72c81caf8d2da5`.
- PyTorch `2.11.0+cu128`, Transformers `5.16.1`, BF16, SDPA, CPU 스레드 4, KV 캐시 켬.
- 모델 파일 다운로드 후 네트워크 없이 로컬 추론. 이미지 업로드/외부 번역 요청 없음.
- 사용자 스크린샷 3개에서 채팅 영역만 추출. 화면 오른쪽 번역 오버레이는 제외.
- 각 엔진에 같은 PNG를 제공하고 SHA256을 확인. Paddle에 입력한 텍스트는 `OCR:`뿐.
- Windows는 현재 publish DLL의 원본 인식과 행 선택을 사용. EN/JP와 EN/JP/KO 각각 비교.
- 확대 보정, 실시간 중복 필터, 번역은 제외. Windows OCR 전체 제품 성능의 대표값은 아님.
- 정답은 화면을 보고 작성. 정답/사전/번역 결과는 모델에 제공하지 않음.

## 결과

시간은 같은 입력을 두 번째 읽었을 때의 전처리+인식 시간. 최초 모델 로드는 별도 약 2초이며
Python/라이브러리 시작 시간까지 포함한 앱 준비 시간은 아니다.

| 사례 | Windows EN/JP | Windows EN/JP/KO | PaddleOCR-VL | Paddle 인식 내용 |
|---|---:|---:|---:|---|
| 방송 문구 + ミッド 2 / mid 2 / 미드 둘 | 0.05초 | 0.11초 | 2.53초 | 공백 제외 수동 전사와 일치 |
| 시스템 문구 + 일본어 브리핑 | 0.09초 | 0.17초 | 4.60초 | 시스템 문구 정상, 二→ニ 혼동 2곳, 입력 커서 `\|` 추가 인식 |
| わかりました + ミッド2 + hello 반복 | 0.03초 | 0.08초 | 1.60초 | 공백 제외 수동 전사와 일치, 반복 줄 유지 |

Windows EN/JP에서는 한국어 방송/시스템 문구가 가짜 일본어로 나왔다.
EN/JP/KO로 늘리면 방송 문구는 정상화됐으나, 시스템 사례의 행 선택과 짧은 혼합 채팅은 여전히 깨졌다.
즉, 한국어 엔진 추가만으로 모두 해결되지는 않았다.

Paddle의 PyTorch 피크 할당 메모리는 약 1,822~1,841MiB, 피크 예약은 최대 1,924MiB였다.
CUDA 드라이버/다른 앱까지 합친 전체 VRAM 사용량이 아니다.

초기 공식 체크포인트 기본 설정(`use_cache=false`)에서는 약 13~22초, 긴 사례는 45초 제한으로 잘렸다.
KV 캐시를 켜고 CPU 스레드를 4로 제한한 비교에서는 모든 사례가 완료됐다.
두 설정을 함께 바꿨으므로 개선 전부를 캐시 하나의 효과로 단정하지 않는다.

## 남은 통합 조건

1. 전체 화면이 아닌 채팅 영역만 읽고, 변화 없을 때 호출하지 않는다.
2. `(시스템)/(방송)`과 `닉네임:`을 읽은 뒤 본문을 분리한다. OCR은 번역/의미 추측을 하지 않는다.
3. 새 본문만 번역하고 중복·입력창 문구를 제외한다. `二/ニ`는 문맥 검증 없이 일괄 치환하지 않는다.
4. OCR 지연/취소/불완전 생성 상태를 표시하고 누적 요청을 만들지 않는다.
5. 기존 번역 모델과 GPU 동시 사용 및 실제 게임 프레임 영향을 확인한 뒤 기본값 여부를 결정한다.

아직 이 조건들을 앱에 연결한 것은 아니다. 이번 변경은 재현 가능한 비교 환경과 측정 결과다.
상시 서버·시작 프로그램을 등록하지 않았으며 테스트 프로세스 종료 시 모델 메모리는 해제된다.
