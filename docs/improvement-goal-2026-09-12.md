# 번역 품질 개선 Goal — 완료 기록

기준 버전: **v0.4.0-beta 유지**. 2026-09-12 사용자 요청에 따라 리뷰 후 개선 Goal로 전환했다.

## 근거와 범위

- 최신 `NEXT_AGENT_HANDOFF.md`, `review-2026-09-12.md`, `translation-quality-2026-09-12.md`를 참고했다.
- 이전 리뷰 560건은 수정 전 기준선이며 이번 결과와 혼합하지 않는다. 80상황×4방향 320건, 같은 30상황의 7B·Lite 각120건이다.
- 목적은 관찰된 오류의 원인 수정과 회귀 확인이다. 임의의 자연어에 오역이 전혀 없음을 보증하는 목표가 아니다.
- 사용자 기존 docs·동기화 스크립트 변경을 보존한다. 운영 서버 배포·GitHub 게시·버전 변경은 하지 않는다.

## 구현한 수정 (후속 검증 진행 중)

- 장소 단독 입력에 임의 인원·헤븐을 붙이지 않고 알려진 장소를 그대로 지역화.
- 로테 규칙이 잡담·복합 문장의 나머지를 삼키지 않도록 전체 문장·유효 장소 범위 제한.
- 방향별 인원, A 말고 B 등의 명시적인 교정 문법을 완전히 매칭할 때만 규칙 번역.
- 일본어 인원 접미사 `人` 보존. 일본어 조사, 한글 인원 표현, 시간 관용구를 수치·방향 검사에서 처리.
- 숫자 뒤 `이/가`를 `명`으로 바꾸던 후처리 제거. `3900이 → 3900명`은 모델 자체 외에 앱 후처리에서도 발생했다.
- 부정·추측 접두어를 무조건 붙여 의미를 복구한 것처럼 보이게 하지 않음.
- 긴 예시 프롬프트 대신 짧은 문맥·관련 용어와 실제 원문. `ロー`가 `ローテ`의 일부로 매칭되는 충돌 차단.
- 위치·인원·수치의 추가/변경 검사. 송신 서비스와 수신 최종 표시 전에 검사. 최종 검사 실패한 수신은 표시·캐시하지 않음.
- 숫자 단위가 인원·횟수로 바뀌는 일부 패턴과 깨진 토큰·프롬프트 누출 검사. 완전한 의미·행위자 판별기는 아님.
- 번역 캐시는 띄어쓰기·대소문자를 구분하고 엔진·모델·서버 지역·사용자 사전 문맥 포함. 비동기 요청별 설정 스냅샷 사용.
- 송신에서 포커스를 강제로 되찾지 않음. 입력 재확인·새 클립보드 확인·변경 시 붙여넣기 취소. 실제 입력과 검사는 원자적이지 않으므로 극히 짧은 경쟁 구간까지 보증하지 않음.
- Fast/Hybrid 두 화면 합의 때 Windows OCR로 돌아가던 경로 수정. 엔진별 품질 점수 스케일 분리.
- 테스트·빌드 실패 시 중단. 클라이언트·사이트 배포는 새 staging에서 생성 후 교체하고 해시·파일 manifest 제공.

## 추가 진단

`artifacts/quality-20260912/`에 수정 단계별 결과를 별도 보관한다. `after-phase1`~`after-phase4`는 개발 중간 검사이며 최종 릴리스 품질 수치가 아니다.

- Lite 설치 모델4쌍 model/tokenizer 파일 SHA256 모두 검사 통과.
- 앱 전처리 없는 raw decode 10예문×beam1/2/4와 Argos 기본 옵션 비교10건에서도 잘못된 뜻·무관한 출력 재현. beam만 높이는 패치는 채택하지 않음.
- 모델 템플릿 확인: 설치1.8B는 공식 Hy-MT2 GGUF Q4_K_M 계열. 7B와 입력 특수 토큰이 다름을 기존 분기에서 유지.
- 프롬프트 비교60 raw 호출 및 단계별320건 재실행. 간단한 프롬프트는 일부 조건문·잡담을 개선했으나 작은 모델의 행위자·시제·발화 의도 오역은 남음.

참고: [Hy-MT2 공식 사용 예](https://huggingface.co/tencent/Hy-MT2-1.8B), [Argos 실제 디코딩 구현](https://github.com/argosopentech/argos-translate/blob/master/argostranslate/translate.py). 공식 형식을 참고했으나 설정만 같다고 동일 품질을 보증하지 않는다.

## 완료 결과

1. 최종 DLL로 동일320+120+120 및 추가16상황×4방향×2모델=128건, 합계688건을 검사하고 전수 검토했다. 재실행에서 같은 출력은 정확히 대조하고 변경된 출력은 다시 판정했다. 추가 표본도 수정에 사용했으므로 최종은 미공개 held-out이 아니라 회귀 검사다.
2. 단위 테스트249개, 브리핑·품질 파이프라인 검사 통과. Arena Windows/Fast/Hybrid 4시나리오×3건 통과. Hybrid는 FastOnly이며 VL fallback·실게임4K/FPS는 미검증으로 남긴다.
3. dotnet/tar 실패 주입과 실제 제한환경 NuGet 실패에서 패키징 중단·이전 아카이브 보존을 확인했다. 정상 권한 재빌드는 성공했다.
4. README·사이트·인수인계·재검사 절차를 갱신했다. 사이트 GET/HEAD·웹훅 회귀 검사 통과. v0.4.0-beta를 유지하고 클라이언트14파일·사이트17파일의 manifest/SHA256 및 테스트 DLL 일치를 검증했다.
