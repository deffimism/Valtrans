# 번역·OCR 개선 결과 — 2026-09-12

기준 **v0.4.0-beta 유지**. [수정 전 리뷰](translation-quality-2026-09-12.md)와 [Goal 변경 기록](improvement-goal-2026-09-12.md)을 바탕으로 코드 수정과 추가 검사를 진행했다. 사용자 기존 변경을 보존했으며 서버/GitHub 배포는 하지 않는다.

## 1. 검사 방법과 한계

최종 빌드로 기존560건+추가128건=**688건**을 실제 로컬 서비스에 요청했다. 규칙·프롬프트·모델·Lite 대체·최종 검증을 포함한 앱 번역 서비스 검사이며 OCR과 게임 입력은 제외한다. 결과 전체를 원문과 대조했고 재실행에서 동일한 출력은 정확히 비교, 변경된 출력은 재판정했다.

- A: 의미 보존·사용 가능, W: 이해 가능하지만 어색/모호, E: 의미 오류, X: 예외/차단/시간 초과.
- 에이전트 수동 판정이며 독립된 원어민 평가가 아니다. 문맥이 부족한 문장은 reference의 의도를 기준으로 평가했다. validator PASS를 정답으로 세지 않았다.
- 원래80상황과 공통30상황은 수정에 사용했다. 추가16상황도 검사기 오탐 수정에 사용했으므로 최종에는 엄밀한 미공개 held-out이 아니라 추가 회귀 표본이다. 일반적인 번역 정확도로 홍보하면 안 된다.
- 저장된 서버 지역 JP, 게임 VALORANT, 잡담 포함, 순차 실행, 요청당30초, RTX4070 SUPER 환경. 게임 GPU 경합·OCR·대기열·UI 표시 지연은 시간에 포함하지 않는다. 첫 로드와 예열 호출이 혼합되어 있다.
- 실행 스크립트/예문: [재검사 절차](../testdata/translation-quality/README.md).

## 3. 고친 원인

- 앱 후처리가 `3900이`를 `3900명`으로 바꾸던 결함, 일본어 `人` 손실, 아직/우리 뒤/숨어있음 손실을 제거.
- 지명 단독에 인원을 만들지 않음. 위치·인원 정정 규칙을 전체 문장에 한해 적용해 뒤 절/부정 대상을 보존.
- 방대한 고정 예시 대신 짧은 게임 문맥과 관련 용어. `ロー`가 `ローテ` 내부에 매칭되지 않게 수정.
- 후처리 완료 뒤 최종 검사. 위치·인원·방향·수치 추가/변경, 일부 단위 오류·깨진 토큰·지시문 누출을 거절.
- 일본어 `するなら` 조건형, 시간 의미 `前に`, `right back`/`잠시 뒤`, `unknown`/`모르다`, 짧은 `ミッド二つ` 검증 오탐 보정.
- Lite의 일반 화장실 문장에서 발생한 무관한 성적 단어 생성 일부를 차단. 일반 욕설/채팅 검열 기능은 아님.
- 설정별 캐시 분리와 요청별 사전 스냅샷. 번역 도중 설정이 바뀌면 이전 결과로 송신 교체/오버레이 표시하지 않음.
- 송신에서 강제 포커스 복귀 제거, 현재 입력·새 클립보드·포커스를 재확인. 검사와 실제 입력 사이 극히 짧은 경쟁 구간은 남음.
- Fast/Hybrid 전체 영역 합의도 선택한 엔진으로 수행하고 품질 점수 척도를 Windows와 구분.
- 테스트/빌드 실패 전파, 새 staging 패키징, 버전·내부파일·SHA256 검증. 실패 시 이전 배포물을 새 빌드처럼 취급하지 않음.

## 4. 아직 남은 품질 문제

| 구성 | 원문 | 실제 출력/문제 |
|---|---|---|
| 1.8B | 오늘 처음 이겼네 기분 좋다 | `I lost today for the first time...` 승패 반전 |
| 1.8B | 플래시 온다 뒤돌아 | `Flash coming, flanking` 행동 변경 |
| 1.8B | 뒤도는 중이니까 조금만 버텨 | `Back is exposed...` 주체·상황 변경 |
| 1.8B·7B | 잘 부탁드립니다 | `Take care` 발화 의도 차이 |
| 1.8B·7B | 지금 들어가도 돼 | 허락 문맥을 질문으로 해석 가능 |
| 7B | スパイクを拾わずに射線を見て | 지시를 과거 서술로 바꿈 |
| Lite | 렉이 심해서 움직이기 힘들어 | `lex is easy to move` 의미 반전 |

Lite 설치 model/tokenizer4쌍은 정상 SHA256이었다. 원시 모델10예문×beam1/2/4 및 Argos 옵션10건에서도 오역이 남아 beam을 올리지 않았다. 복합 모드의 Lite 대체 정책은 유지했다. 비교할 때 **로컬 AI**를 직접 선택하면 Lite 대체를 끌 수 있다. 7B가 이번 문장에서는 더 나았지만 게임 성능까지 고려한 기본값 변경은 하지 않았다.

검증기는 완전한 의미 판별기가 아니다. 화자/행동/부정 범위/발화 의도/단위를 놓칠 수 있고, 정상 표현을 차단할 수도 있다. X에는 원문만으로 정상/오역 여부를 구별할 수 없는 차단도 있다. 전송 전 확인은 필요하다.

## 5. 회귀·OCR·배포 검증

- 단위 테스트249개 통과. 프롬프트·양방향 규칙·최종 검사·캐시·송신 입력 경쟁을 포함.
- `Test-BriefingModel.ps1`, `Test-QualityPipeline.ps1` 통과. 후자는 실제 모델 품질이 아닌 모의HTTP·합성 OCR 후보·Lite 응답 프로토콜 검사도 포함.
- 실제 Arena 캡처: Windows 기본3/3, Fast 혼합3/3, Fast 전체합의3/3, Hybrid 전체합의3/3. 전체합의 recognizer 기록으로 Windows로 돌아가지 않음을 확인했다. 당시 합의 P50총지연 Fast1749.5ms/Hybrid2095.2ms. 마지막 의미 검사 소수 변경 이전 빌드에서 실행했다.
- **Hybrid Arena는 FastOnly**다. VL fallback 실제 경합, 실게임4K, FPS, 다양한 화면비 실측은 미검증. 실패한 제한환경 첫 OCR 준비 로그와 정상 권한 재검사 로그를 구분한다. 테스트 후 설정·Arena 레이아웃 원본 해시를 확인해 복원했다.
- 사이트 GET/HEAD 약관·개인정보·후원 이미지, Fairy 서명 정상 요청/중복/개인 필드 미저장/관리 접근 보호/health 검사 통과. 오래된 고정버전 테스트를 현재 csproj와 비교하도록 수정했다.
- 실패 주입: dotnet exit7이면 단위검사/클라이언트 패키징 중단, tar exit8이면 사이트 패키징 중단. 이전 아카이브 해시 보존 확인. 실제 제한환경 NuGet 실패에서도 이전 ZIP을 교체하지 않았다.
